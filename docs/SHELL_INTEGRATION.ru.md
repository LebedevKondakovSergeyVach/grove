# Интеграция с оболочкой

`grove init` будет печатать функцию оболочки. Родительская оболочка выполняет этот вывод. Этого вывода в репозитории ещё нет.

<!--site:steps-->

1. zsh: `eval "$(grove init zsh)"`
2. bash: `eval "$(grove init bash)"`

<!--site:/steps-->

`grove init` <!--site:badge text="Planned"--> печатает функцию оболочки. Значения, которые оболочка выполняет, экранирует одна функция в коде Rust. Когда появится `shell/`, файлы проверяются через `zsh -n` и `bash -n`.

<!--site:aside type="note"-->

Сам `grove init` родительскую оболочку не меняет. Оболочка должна выполнить то, что он напечатал.

<!--site:/aside-->
