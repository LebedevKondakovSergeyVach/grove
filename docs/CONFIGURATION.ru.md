# Конфигурация

Два файла TOML. Команды, которая их записывает, ещё нет.

<!--site:steps-->

1. **Workspace.** `.grove/workspace.toml` в корне workspace. В нём модули (имя, путь, remote), шаблон задачи, форматы веток, базовая ветка и набор проверок перед переключением.
2. **Настройки.** `settings.toml` в каталоге конфигурации ОС. Оболочка (`zsh` или `bash`), значки, цвет, язык (`ru` или `en`) и remote по умолчанию.
3. **Приоритет.** Сначала флаг, затем `GROVE_WORKSPACE`, `GROVE_SETTINGS` или `GROVE_LANG`, затем файл. Если файл не разбирается, команды берут значения в памяти и отказываются перезаписывать этот файл.

<!--site:/steps-->
