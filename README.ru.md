# Grove

Версия 0.1.0, MVP. Единственная ветка — `main`. Команды workspace ещё не реализованы.

Grove выполняет один git-процесс для набора связанных репозиториев.

`grove switch` проверяет каждый репозиторий до того, как изменить хотя бы один. Если переключить нельзя хотя бы один, не меняется ни один. Если сбой случился после того, как часть репозиториев уже переключена, они возвращаются на прежние ветки. Проверка включает skip-worktree и assume-unchanged.

Команда — `grove`. Имя пакета Cargo — `grove-git`.

## Workspace

Файл workspace перечисляет репозитории: имя, путь и remote. Имена веток задачи и базовая ветка задаются в этом файле, а не вшиты в программу.

Пользовательские настройки задают оболочку, язык, цвет и remote по умолчанию.

## Команды

Бинарник не опубликован. Устанавливаемого пакета пока нет.

- `grove status` — ветка, upstream и локальные изменения каждого репозитория
- `grove fetch` — fetch каждого репозитория
- `grove pull` — fast-forward каждого репозитория
- `grove switch <задача>` — перевести все репозитории на задачу или откатить
- `grove new <задача> <slug>` — создать ветку задачи от базовой ветки
- `grove init zsh` — вывести настройку оболочки для `eval`

Первый срез: status, switch, fetch, предварительная проверка и файл workspace. Терминальной панели в этом срезе нет.

Операции git идут через бинарник `git` из `PATH`.
